# NOVA — Focus Workspace

A responsive product landing page developed using HTML5, CSS3 and JavaScript as part of the Cognetix Technology Full Stack Developer Internship.

## Features

- Responsive hero section
- Product features section
- Benefits / Why NOVA section
- Testimonials with ratings
- Call-to-action sections
- Responsive navigation
- Mobile menu
- Smooth scrolling
- Interactive feature details
- Get Started form
- Toast notifications
- Scroll reveal animations

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Flexbox
- CSS Grid
- Responsive Media Queries
